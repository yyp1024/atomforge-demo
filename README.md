# AtomForge · 智能体驱动的应用生成器

> Atoms 笔试 Demo —— 用一句自然语言，让 Agent 为你生成一个**可运行、可迭代、可导出**的网页应用。

**在线体验**：https://fcncajfmnxex.doubaoapps.com/app/app_17eubkd23bd

**一句话**：深色工程实验室风格的工作台里，输入「做一个番茄钟，橙色主题」→ Agent 流水线解析需求、规划结构、生成 3 文件代码、在沙箱 iframe 里实时渲染；你还能继续对话换主题色、改布局，或直接打开代码面板编辑后热更新。

---

## 功能一览

| 类别 | 能力 |
| --- | --- |
| 核心主流程 | 自然语言 → 需求解析 → 结构规划 → 代码生成 → 沙箱编译 → 实时预览（6 步流水线动画） |
| 模板引擎 | 8 个可交互生成模板：待办清单 / 番茄钟 / 计算器 / 知识测验 / 便签板 / 倒计时 / 幸运转盘 / 习惯打卡 |
| 对话式迭代 | 继续对话换主题色、切换深浅色、改名、布局紧凑化，保留原模板语义 |
| 代码可编辑 | 3 文件（index.html / style.css / app.js）代码面板，编辑 → 应用 → 预览热更新 |
| 数据持久化 | 项目、设置、引导状态全部 localStorage 持久化，刷新不丢；多标签页 storage 事件实时同步 |
| 生成应用内持久化 | 每个生成应用自带本地保存（如待办任务、番茄统计、习惯打卡记录，key 前缀 `af-`） |
| 分享与导入 | 分享链接（参数压缩为 base64url）→ 新窗口/新设备导入项目 |
| 导出与备份 | 下载生成应用的 HTML 单文件；设置页导出全部项目 JSON 备份 |
| 新手引导 | 首次进入三步引导 + 个性化昵称问候 |

## 快速开始

纯静态单文件，零依赖、零构建：

```bash
# 方式一：直接双击 index.html 用浏览器打开
# 方式二：起一个本地静态服务
python -m http.server 8612
# 然后访问 http://127.0.0.1:8612/
```

## 技术选型与取舍

- **零依赖单文件 HTML**：原生 JS + hash 路由 + 重渲染函数，任何静态托管都能跑，评审者双击即可体验，无构建链风险。
- **规则引擎 + LLM 预留**：演示版用确定性规则引擎（8 模板 + 意图识别）保证每次生成稳定可复现；`ENG.LLM.enabled` 预留 OpenAI 兼容接口，接入后即升级为真实 Agent 生成。
- **localStorage 持久化**：评审场景无需注册登录，刷新/换设备（分享链接）均可恢复，同时规避了后端运维成本。
- **srcdoc iframe 沙箱**：生成代码隔离渲染，不影响宿主页，天然防止生成代码逃逸。

## 已知限制

- 分享链接只携带生成参数（模板 + 配置），不携带手工编辑后的代码正文；导入后按模板重新合成。
- 规则引擎覆盖 8 个模板场景；超出模板的自然语言需求会做意图近似映射并明确提示。
- 无后端：多人实时协作、云端项目同步未实现（扩展规划见说明文档）。
